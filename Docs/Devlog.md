# 《七月半》首次开发日志

整理日期：2026-10-11。范围：金元宝小游戏从真实折纸原型到记忆顺序连线 V0.2，以及首次 GitHub 上传准备。

本日志根据当前项目代码、场景、项目外已有开发说明及验收报告整理。V0.2 是本次成果整理的版本标记；没有为此重命名原有脚本或场景。本次未重新执行 Unity 运行测试。

## 起点：让纸扎店的劳动成为可玩的交互

《七月半》围绕儿子在父亲去世后代守纸扎店七个营业日展开。金元宝制作是计划中「备货 → 制作 → 交易 → 结算」循环的手作环节，先以独立小游戏验证操作手感与反馈，再接入经营系统。

第一阶段在 `Shop_Prototype` 的 Canvas 上使用长方形金纸，尝试模拟折元宝的实际动作。`GoldPaperFold.cs` 和 `GoldPaperFoldLayer.cs` 实现从下沿抓取、沿水平中线向上翻折，通过虚拟三维旋转与透视投影绘制纸张正反面、阴影和折痕。未到完成角度时回弹，到达阈值后自动折好并锁定。

现有首折验收记录覆盖 60/120/155 度拖动、正反面、回弹、完成事件仅触发一次、输入隔离及真实 UI 拖拽事件链。这个阶段验证了第一折交互，没有完成整个金元宝的真实折叠流程。

## 迭代一：从真实折纸转向记忆描线 V0.1

为了先完成简短、清晰、可重试的小游戏，不再扩展真实纸张翻折。原场景与折纸脚本保留，复制出 `Assets/_Project/Scences/GoldIngot_V01.unity`，复用 Main Camera、Canvas、GoldPaper 和 EventSystem；小游戏场景停用旧折纸组件，使用 `GoldIngotMemoryGame`。

V0.1 的流程为「选择难度 → 短暂展示路线 → 隐藏 → 从起点按住左键凭记忆描线 → 松手判定 → 元宝成型」。三个难度使用小型路线库与镜像变体，最初分别为 2–3 / 4–5 / 6–7 个转折，记忆时间为 3.5 / 4.5 / 5.5 秒，奖励为 1 / 2 / 3 扎。

判定要求按顺序经过关键点，并限制路径走廊、越界、倒走和抄近路。成功时金纸淡出、元宝弹出，增加会话计数；失败展示答案并允许重试。这一阶段已形成可完整走通的展示、输入、判定与奖励闭环。

## 迭代二：补齐起终点与轨迹判定

随后加入持续可见的绿色起点与红色终点，明确左键开始与结束规则。判定进一步分析平滑后的输入轨迹，检查真实转折位置、角度、方向、额外转折和整体形状，以减少漏点或错误轨迹被判成功。

这个阶段采用折点评分 70% 与形状评分 30%，并保留硬性检查。现有验收记录包含 576 个路线与宽高比组合、1152 条有效的抖动/圆角轨迹及非法路径反例。

这些算法和 Editor 回归工具仍保留在项目中，但当前 V0.2 已切换到顺序连点判定，旧角度与形状评分不参与当前通关逻辑。

## 迭代三：记忆折点顺序 + 一笔连线 V0.2

最终将挑战重点调整为记住折点顺序并避开干扰点。金纸、三种难度、原元宝动画与会话奖励继续复用；玩法仍运行在 `GoldIngot_V01.unity`。

### 最终规则

| 难度 | 正确折点（不含两端） | 干扰点 | 展示时间 | 奖励 |
| --- | ---: | ---: | ---: | ---: |
| 简单 | 6 | 2 | 7 秒 | 1 扎 |
| 普通 | 8 | 3 | 7 秒 | 2 扎 |
| 困难 | 10 | 4 | 7 秒 | 3 扎 |

- 记忆阶段逐段播放路线，末尾短暂保留完整路线；结束后只隐藏线，全部候选点和起终点继续可见。
- 正确折点与干扰点没有编号、颜色或尺寸差异，不提示下一正确点。
- 玩家从绿色起点附近按住左键，连续按正确顺序连点。点间轨迹可以自由弯曲，无需复刻原线段形状。
- 线端靠近点时平滑吸附；连接后圆点轻微放大再恢复，已连接线段固定在点中心。
- 错点、跳点、乱序、未完成时越界或提前松手均失败，不发奖。失败答案显示约 1 秒，重试立即可用。
- 选择难度、成功后再来一张、失败重试均生成新布局。
- 连齐红色终点时立即锁定完成；之后移开鼠标、离开金纸或经过其他点再松手，仍然成功。重复松手不重复发奖。

### 实现重点

`GoldIngotSequenceRules.cs` 在归一化纸面上随机生成候选点，按纸张宽高比换算距离。布局保证点位间隔，并搜索转向明显、避开其他候选点吸附区的正确路线，减少正常连线误碰干扰点的情况。无法满足参数组合时显示调整提示，不静默降低点数。

输入判定检测鼠标移动段与候选点圆的最早接触时刻，依次处理触碰；快速拖动时也能识别经过的错误点。默认连接半径为纸张高度的 0.065，视觉吸附半径为 0.095，候选点间距配置为 0.20，实际间距至少大于两倍吸附半径。参数可在 `GoldIngotMemoryGame` 的 `Sequence` 中调整。

代码职责：

- `GoldIngotMemoryGame.cs`：状态机、输入、UI、逐段展示、吸附反馈、成功动画和会话计数。
- `GoldIngotSequenceRules.cs`：可调配置、随机布局、顺序与完成锁定判定。
- `GoldIngotRouteRules.cs`：路线数据及保留的早期严格轨迹判定。
- `GoldIngotStrokeGraphic.cs`、`GoldIngotIconGraphic.cs`：线条、圆点与元宝占位图。
- `Editor/GoldIngotSequenceTests.cs`、`Editor/GoldIngotV01Tools.cs`：规则及真实 Input System / UI 验收工具。
- `GoldPaperFold.cs`、`GoldPaperFoldLayer.cs`：保留的首折原型。

## V0.2 成果与下一步

本阶段完成了可独立运行的三难度记忆连线小游戏：随机布局、干扰点、逐段记忆、平滑吸附、一笔顺序判定、失败重试、成功动画、完成锁定和防重复结算。

目前奖励仅保存在单次运行中。全局库存、原料消耗、顾客订单、报价、现金结算、存档、七天剧情与正式美术声音仍待接入。下一步先建立最小库存接口，让小游戏产出进入经营循环，再完成一个营业日的订单与结算。
